# Clean Generic Portfolio

Static GitHub Pages portfolio using the supplied portfolio content.

## SEO included

- descriptive page title and meta description
- English + Swedish service terminology used naturally in visible content
- Open Graph / Twitter metadata
- `Person` and `WebSite` JSON-LD structured data
- `sitemap.xml`
- `robots.txt`
- semantic headings and crawlable links

Before publishing, replace `https://YOUR-DOMAIN.example/` in `index.html`, `sitemap.xml`, and `robots.txt` with your real domain.

## Important

SEO improves discoverability; it cannot guarantee a particular Google ranking. Google recommends people-first content, useful titles/descriptions, good site structure, crawlable links, and Search Console rather than keyword stuffing.

## GitHub Pages

Upload the contents of this folder to a repository and enable GitHub Pages from the `main` branch, root folder.
